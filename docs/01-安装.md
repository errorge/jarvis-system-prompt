# 01 · 安装

## 环境要求

- magpie（需支持 gateway middleware 与插件页面；0.1.33xx 已验证）
- 跑测试需要 Node.js ≥ 18（仅开发/验证时用，运行插件不需要）

## 方式一：一键脚本

```bash
cd jarvis-system-prompt
./install.sh
```

脚本会按顺序找 magpie：`PATH` 里的 `magpie` → `/Applications/magpie.app/Contents/MacOS/magpie`，
然后执行 `magpie plugin add <本目录>`。找不到会报错并提示手动安装。

## 方式二：本地目录

```bash
magpie plugin add /path/to/jarvis-system-prompt
```

## 方式三：压缩包 / GitHub

```bash
magpie plugin add /path/to/jarvis-system-prompt-0.2.0.tgz   # npm 包格式
magpie plugin add github:<owner>/jarvis-system-prompt       # 发布到 GitHub 后
```

## 安装后确认

```bash
magpie plugin list
# 应看到：
#   <路径或包名>  on
#     gateway middleware  onRequest
#     page  Jarvis (reads nothing)
```

打开 magpie 侧栏 **插件 → Jarvis（贾维斯）** 应能看到设置页。
看不到时：完全退出 magpie 再启动一次（插件列表有缓存）。

## 更新

- 只改配置：设置页保存或 `magpie plugin options …`，**立即生效**
- 改了 `prompt.js` / `jarvis.middleware.js` / `page/`：重新 `magpie plugin add <目录>`
- GitHub 安装的用户：`magpie plugin update`

## 卸载 / 临时关闭

```bash
magpie plugin off jarvis-system-prompt    # 关闭：所有请求恢复原提示
magpie plugin on  jarvis-system-prompt    # 重新启用
magpie plugin rm  jarvis-system-prompt    # 彻底移除
```

关闭是干净的：不留钩子、不改 agent 配置文件。
