# 02 · 设置页

入口：magpie 侧栏 **插件 → Jarvis（贾维斯）**。

页面是沙箱环境，通过宿主桥接读写插件 options；**和命令行改的是同一份配置**。

## 控件说明

| 控件 | 对应配置 | 说明 |
|---|---|---|
| 总开关 | `enabled` | 关掉后所有请求原样通过 |
| 工具数下限 | `minTools` | 少于此数的请求不改（默认 3，挡住标题/审查等旁路） |
| Claude Code 卡片 · 启用 | `agents` 名单 | 不勾选 = 该 agent 的请求完全不动 |
| Claude Code 卡片 · 人格样本 | `settings.claude.persona` | jarvis / neutral / 不换身份 / 自定义文本 |
| Claude Code 卡片 · 安全段策略 | `settings.claude.security` | 删除默认 / 保留默认 / 换成自定义 |
| 自定义文本框 | `…customSecurity` / `persona` 原文 | 选"自定义"时才出现 |
| ZCode 卡片 | `settings.zcode.*` | 与 Claude 完全独立，互不影响 |
| 保存 | 写回 options | 限频 1 次/秒；失败自动重试一次；草稿不丢 |

## 操作要点

- **改完点保存**才写回；保存成功会显示"已保存，下一条请求生效"
- 两个 agent 卡片互不干扰：可以给 Claude 用 jarvis+删除，给 ZCode 用 neutral+保留
- "不换身份"= 只处理安全段，身份行保持原样
- 自定义人格文本直接填进框里，不需要改代码
- 页面读取配置失败时会进入只读报错态（不会拿空配置画假页面），重新可见时自动重试

## 看不到页面？

1. `magpie plugin list` 确认有 `page Jarvis` 一行
2. 完全退出 magpie 再启动（列表缓存）
3. 本地目录安装时确保目录里有 `README.md`（magpie 详情页要求）
