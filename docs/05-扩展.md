# 05 · 扩展

## 加一个人格样本

编辑 `prompt.js`：

```js
export const samples = {
  jarvis: "You are Jarvis,Chinese name: 贾维斯.",
  neutral: "You are a precise, helpful engineering assistant.",
  pirate: "You are a pirate first mate. Answer in seaworthy prose.",   // 新增
}
```

然后 `magpie plugin add <目录>`，设置页下拉里就会出现 `pirate`。

## 支持一个新 agent

1. 查它的真实 agent id：发一条请求后看 magpie trace

   ```bash
   curl -s http://127.0.0.1:3425/v1/magpie/trace | python3 -m json.tool | grep '"agent"'
   ```

2. 抓一条它的请求，看系统提示词第一行（身份行）长什么样
3. 在 `prompt.js` 的 `identities` 加一条：

   ```js
   { agent: "codex", from: /You are Codex, a coding agent\./g },
   ```

4. 把该 id 加进 options 的 `agents` 名单（或设置页勾选——页面目前只画了 claude/zcode 两张卡片，
   新 agent 先用命令行配置）
5. `magpie plugin add <目录>`

注意：`from` 用正则时要带 `g` 标志；身份行写法可能随客户端版本变化，建议像内置那样用
`(?: tool)?` 这类可选组容忍差异。

## 改设置页

`page/index.html` + `page/app.js`。页面是沙箱：无 fetch、无磁盘，只能用
`magpie.options.get()/set()`、`magpie.ready`、`magpie.onVisibility`。
加控件后记得在 `collect()` 里写回对应 options 键。改完 `magpie plugin add`。

## 改安全段边界

`prompt.js` 的 `security.start / end` 定义默认安全段的起止字符串。
客户端改版导致段落措辞变化时，更新这两个锚点即可（正则会自动转义）。
