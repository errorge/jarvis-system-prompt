# 04 · 样本与安全策略

## 人格样本（persona）

取值规则（按顺序）：

1. 是 `prompt.js` 里 `samples` 的键 → 用该样本的身份行文本
2. 否则当作**自定义原文**直接使用
3. 空字符串 `""` → 不换身份，只处理安全段

内置样本：

```js
samples = {
  jarvis:  "You are Jarvis,Chinese name: 贾维斯.",
  neutral: "You are a precise, helpful engineering assistant.",
}
```

身份行匹配正则也在 `prompt.js`（`identities`），目前覆盖：

- Claude Code CLI：`You are Claude Code, Anthropic's official CLI (tool)? for Claude.`
- Claude Agent SDK：`You are a Claude agent, built on Anthropic's Claude Agent SDK.`
- ZCode：`You are ZCode, an interactive agent`

匹配不到身份行时**不会乱改**，只处理安全段。

## 安全段三档（security）

默认安全段指原文中这一段：

```
IMPORTANT: Assist with authorized security testing, … defensive use cases.
```

| 档位 | 行为 |
|---|---|
| `remove` | 整段删除 |
| `keep` | 原样保留 |
| `custom` | 原文有该段 → 替换成 `customSecurity`；原文没有 → 插到系统提示最前 |

## 幂等保证（为什么不会重复插入）

magpie 会把 system 拆成多个块、在多个协议阶段调用中间件，客户端也可能把同一份提示词发在两处
（顶层 `system` + 一条 `system` 消息）。本插件：

- 处理前先扫**整个 system 的所有块**：任何一块已含 `customSecurity` → 标记完成，不再插入
- 默认安全段只**替换注入一次**；其余出现处只删不插
- 因此重试、分块、跨阶段都不会产生第二份

`remove` / `keep` 天然幂等。

## 成本提示

`custom` 注入的文本每次请求都会计费。注入 2 万字符的规范 ≈ 每请求 +5,000 token。
只想"去限制"而不加内容时，用 `remove` 最省。
