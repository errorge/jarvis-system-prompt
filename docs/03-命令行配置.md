# 03 · 命令行配置

## 查看

```bash
magpie plugin options jarvis-system-prompt          # 当前完整配置
magpie plugin list                                  # 插件开关状态
```

## options 全表

```jsonc
{
  "enabled": true,                 // 总开关
  "agents": ["claude", "zcode"],   // 启用名单；["none"] = 谁也不改
  "minTools": 3,                   // 旁路门禁阈值
  "settings": {
    "claude": {
      "enabled": true,             // 可单独关某个 agent
      "persona": "jarvis",         // 样本名 / 自定义原文 / ""(不换身份)
      "security": "remove",        // remove | keep | custom
      "customSecurity": ""         // security=custom 时的替换文本
    },
    "zcode": { "persona": "jarvis", "security": "remove", "customSecurity": "" }
  }
}
```

没有 `settings` 时回落到顶层 `persona` / `security` / `customSecurity`（旧配置兼容）。

## 常用示例

```bash
P=jarvis-system-prompt

# ZCode 换 neutral 且保留它自己的安全段，Claude 不变
magpie plugin options $P '{"enabled":true,"agents":["claude","zcode"],"minTools":3,"settings":{"claude":{"persona":"jarvis","security":"remove"},"zcode":{"persona":"neutral","security":"keep"}}}'

# 给 ZCode 注入自定义安全规范（替换默认 IMPORTANT 段）
magpie plugin options $P '{"enabled":true,"agents":["claude","zcode"],"minTools":3,"settings":{"claude":{"persona":"jarvis","security":"remove"},"zcode":{"persona":"jarvis","security":"custom","customSecurity":"IMPORTANT: 你的规范全文"}}}'

# 只删安全段、不换身份
magpie plugin options $P '{"enabled":true,"agents":["claude"],"minTools":3,"settings":{"claude":{"persona":"","security":"remove"}}}'

# 单独关掉 ZCode
magpie plugin options $P '{"enabled":true,"agents":["claude","zcode"],"minTools":3,"settings":{"zcode":{"enabled":false}}}'

# 全部关闭
magpie plugin options $P '{"enabled":false}'
```

## 生效规则（重要）

| 改了什么 | 需要做什么 |
|---|---|
| options（配置） | 无需任何操作，下一条请求生效 |
| `prompt.js` / 中间件 / `page/` | `magpie plugin add <目录>` 重新加载 |
| 想临时停用 | `magpie plugin off $P` |

`plugin add` 会重载代码；**不需要重启 magpie**。
